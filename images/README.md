# images フォルダ

店舗の画像を置く場所です。

## 使い方

1. 画像ファイル(例: `viet-nhat.jpg`)を、このフォルダに入れます。
2. `js/data.js` の、そのお店のデータに、次のように書きます。

```js
image: "images/viet-nhat.jpg",
imageSource: "店舗から提供",       // 入手元・利用許可の記録(画面には出ません)
imageCredit: "写真提供: ○○店",     // 画像の下に小さく表示されます(省略してもOK)
```

`image` を書かない(または空にする)お店には、`default-shop.svg`(イラスト)が表示されます。
画像の読み込みに失敗したときも、`default-shop.svg` に切り替わります。

## 使ってよい画像

次のような、**利用の許可を確認できた画像だけ**を使ってください。

- 店舗から提供してもらった画像(使ってよいと確認できたもの)
- 自分で撮影した画像
- 利用条件上、問題のない画像(ライセンスを確認したもの)

Google マップ・食べログ・Retty・Instagram など、第三者のサイトの画像を、許可なくコピーして使うことはできません。

## 画像のおすすめ

- 縦横比は、正方形〜4:3 くらい(一覧では、正方形に切り抜いて表示されます)
- 大きさは、横 400〜800px 程度(大きすぎると、読み込みが遅くなります)

## このフォルダの、ほかのファイル

- `default-shop.svg` : 店舗画像がないときの、デフォルトのイラスト
- `logo.png` : ヘッダーのロゴ(背景は透明)
- `favicon.png` / `apple-touch-icon.png` : ブラウザのタブ・スマホのホーム画面用のアイコン
- `logo-original.png` : 元のロゴ画像(白い背景つき。ロゴを作り直すときの元データ)
